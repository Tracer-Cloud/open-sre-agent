# Jenkins Integration

The Jenkins integration allows OpenSRE to correlate CI/CD pipeline activity with incidents.

## Features

- List Jenkins jobs
- List recent builds
- Fetch build logs
- List running builds
- Inspect pipeline stages

## Configuration

Provide:

- Jenkins URL
- Jenkins username
- Jenkins API token

## Example Use Cases

- Investigating failed deployments
- Correlating alerts with CI/CD activity
- Reviewing pipeline stage failures
