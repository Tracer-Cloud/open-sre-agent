title: "Amazon EKS"
description: "Connect Amazon EKS so OpenSRE can inspect cluster health, deployment status, addons, and Kubernetes workloads during investigations."
---

OpenSRE integrates with Amazon EKS to inspect cluster health, deployment status, managed addons, and Kubernetes workloads during incident investigations.

## Prerequisites

- An AWS account with one or more Amazon EKS clusters
- AWS credentials configured for the runtime
- Permission to access Amazon EKS and the Kubernetes API

## Setup

### Option 1: Interactive CLI

```bash
opensre integrations setup
```

Select **Amazon EKS** when prompted.

### Option 2: Environment variables

Add the following to your `.env`:

```bash
AWS_ACCESS_KEY_ID=your-access-key
AWS_SECRET_ACCESS_KEY=your-secret-key
AWS_REGION=us-east-1
AWS_SESSION_TOKEN=your-session-token    # optional
```

| Variable | Required | Description |
| --- | --- | --- |
| `AWS_ACCESS_KEY_ID` | Yes | AWS access key ID |
| `AWS_SECRET_ACCESS_KEY` | Yes | AWS secret access key |
| `AWS_REGION` | No | AWS region (defaults to `us-east-1`) |
| `AWS_SESSION_TOKEN` | No | Session token when using temporary credentials |

## Verify

```bash
opensre integrations verify eks
```

Expected output:

```text
Service: eks
Status: passed
Detail: Successfully connected to Amazon EKS
```

## Investigation tools

When investigating Amazon EKS alerts, OpenSRE provides:

- **Describe EKS Cluster** — inspect cluster health, Kubernetes version, endpoint, and logging configuration.
- **Deployment Status** — view desired, ready, and unavailable replicas for Kubernetes deployments.
- **Describe Addon** — inspect managed addons such as CoreDNS, kube-proxy, VPC CNI, and the AWS EBS CSI Driver.
- **List Clusters** — discover available Amazon EKS clusters in the AWS account.

All operations are read-only.

## Gotcha

Ensure the configured AWS credentials have permission to access both Amazon EKS and the Kubernetes API. Without the required permissions or a valid kubeconfig, workload inspection may fail even if the cluster itself is reachable.
