## Option 1: Native PowerShell installer

```powershell
irm https://install.opensre.com | iex
```

Then configure your LLM and integrations:

```powershell
opensre onboard
opensre health
opensre integrations verify
```

## Option 2: WSL (Windows Subsystem for Linux)

1. Install WSL: [Microsoft WSL install guide](https://learn.microsoft.com/en-us/windows/wsl/install)
2. Open your Linux distro terminal and follow [Linux (local)](/environments/linux-local)
