---

Build from the repository Dockerfile. It supports two modes via `MODE`:

- `MODE=web` — FastAPI health and investigation API
- `MODE=gateway` — messaging gateway (Slack / Telegram / Discord)

## Prerequisites

Docker Desktop or Docker Engine with enough resources for Python workloads (at least 2 CPU cores and 4GB RAM recommended).

## Build the image

From the repository root:

```bash
docker build -t opensre:latest .
```

## Run web mode

```bash
docker run --rm -p 8000:8000 --env-file .env opensre:latest
curl http://localhost:8000/health
```

## Run gateway mode

```bash
docker run --rm -e MODE=gateway --env-file .env opensre:latest
```

Gateway mode needs messaging credentials (for example `SLACK_BOT_TOKEN` + `SLACK_APP_TOKEN`, or `TELEGRAM_BOT_TOKEN`) plus your LLM provider settings in `.env`.
