Install OpenSRE on macOS, set up your LLM, then try a sample investigation.

## 1. Install

Pick one:

```bash
# Homebrew
brew tap tracer-cloud/tap
brew install tracer-cloud/tap/opensre

# or one-line installer
curl -fsSL https://install.opensre.com | bash
```

You usually don't need `sudo`. If the terminal says `opensre: command not found`, open a new window or add the path the installer printed (often `~/.local/bin`).

In a normal interactive terminal, install may start onboard for you. To skip that:

```bash
curl -fsSL https://install.opensre.com | OPENSRE_AUTO_LAUNCH=0 bash
```

## 2. Set things up

```bash
opensre onboard
```

You'll pick an LLM provider and paste a key or confirm a CLI login. Add tools later, when you need them:

```bash
opensre integrations setup <service>
```

Then check connected tools:

```bash
opensre integrations verify
```

## 3. Try an investigation

```bash
opensre investigate -i tests/e2e/kubernetes/fixtures/datadog_k8s_alert.json
```

Or open the shell and describe what's going on:

```bash
opensre
```
