## 1. Install OpenSRE

```bash
curl -fsSL https://install.opensre.com | bash
```

Or with Homebrew:

```bash
brew tap tracer-cloud/tap
brew install tracer-cloud/tap/opensre
```

The installer does not require `sudo`. It installs into a writable bin directory already on your `PATH` when possible; otherwise it uses `~/.local/bin` and prints how to update `PATH`.

## 2. Onboard

```bash
opensre onboard
```

This configures your LLM provider and optional integrations. When you run the curl installer from an interactive terminal, onboarding starts automatically after install.

## 3. Verify

```bash
opensre health
opensre integrations verify
```
