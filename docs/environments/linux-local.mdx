Install OpenSRE on Linux (laptop, desktop, or a local VM), set up your LLM, then try a sample investigation.

## 1. Install

```bash
curl -fsSL https://install.opensre.com | bash
```

Or with Homebrew on Linux, if you use it:

```bash
brew tap tracer-cloud/tap
brew install tracer-cloud/tap/opensre
```

You usually don't need `sudo`. If `opensre` isn't found after install, open a new terminal or add the bin directory the installer printed (often `~/.local/bin`) to your PATH.

In a normal interactive terminal, install may start onboard for you. To skip that:

```bash
curl -fsSL https://install.opensre.com | OPENSRE_AUTO_LAUNCH=0 bash
```

## 2. Set things up

```bash
opensre onboard
```

Pick an LLM provider and add a key or confirm a CLI login. Add tools later, when you need them:

```bash
opensre integrations setup <service>
```

Then verify connected tools:

```bash
opensre integrations verify
```

## 3. Try an investigation

```bash
opensre investigate -i tests/e2e/kubernetes/fixtures/datadog_k8s_alert.json
```

Or chat with it in the shell:

```bash
opensre
```
