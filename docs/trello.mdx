title: "Trello"
description: "Connect Trello so OpenSRE can view cards and boards during investigations and incident management"
---

When incidents happen, keeping everyone organized matters. OpenSRE connects to Trello so you can create incident cards, track investigation progress, and manage follow-up tasks — all without leaving your incident response workflow.

## What you need

- A Trello account (board access is all that's required)
- An API key and token (we'll show you where to get them)
- The board and list IDs where you want OpenSRE to create cards (optional, but helpful)

## Setting up Trello

### Quick setup

Let's get this connected:

```bash
opensre integrations setup
```

Choose **Trello** and paste your API key and token.

### Manual config: Environment variables

Or add these to your `.env`:

```bash
TRELLO_API_KEY=your_api_key
TRELLO_TOKEN=your_token
TRELLO_BOARD_ID=board_id_optional
TRELLO_LIST_ID=list_id_optional
TRELLO_BASE_URL=https://api.trello.com/1
```

| Variable | Default | Description |
| --- | --- | --- |
| `TRELLO_API_KEY` | — | **Required.** Trello API key |
| `TRELLO_TOKEN` | — | **Required.** Trello API token |
| `TRELLO_BOARD_ID` | _(empty)_ | Optional. Default board ID for card creation |
| `TRELLO_LIST_ID` | _(empty)_ | Optional. Default list ID for card creation |
| `TRELLO_BASE_URL` | `https://api.trello.com/1` | Trello API base URL |

### Save it permanently: Persistent store

You can also save your Trello config to `~/.opensre/integrations.json`:\n\n```json
{
  "version": 1,
  "integrations": [
    {
      "id": "trello-prod",
      "service": "trello",
      "status": "active",
      "credentials": {
        "api_key": "your_api_key",
        "token": "your_token",
        "board_id": "board_id_optional",
        "list_id": "list_id_optional"
      }
    }
  ]
}
```

## Get your API key and token

It's simpler than you might think:

1. Go to [https://trello.com/app-key](https://trello.com/app-key)
2. Your **API Key** is displayed right there on the page
3. Scroll down and click the **Token** button to generate one
4. Authorize it when Trello asks
5. Copy both values and keep them safe

## Optional: Find your Board and List IDs

If you want OpenSRE to create cards in a specific board/list, you'll need their IDs:

**Easy way:** Use the API

```bash
curl "https://api.trello.com/1/members/me/boards?key=${TRELLO_API_KEY}&token=${TRELLO_TOKEN}"
```

**Manual way:**

1. Open your board in Trello
2. Add `.json` to the end of the URL in your browser
3. Search the page for `"id"` and find your board ID
4. Do the same for list IDs within that board

## Token longevity

By default, Trello tokens expire after 30 days without activity. For a token that never expires:

1. Go to [https://trello.com/app-key](https://trello.com/app-key)
2. Find the **Token** section
3. Look for the expiration settings
4. Select **Never** instead of a specific date

## What permissions are needed?

Your token needs:
- **read** — So OpenSRE can view boards, lists, and cards
- **write** — So it can create cards during investigations (optional but useful)

## Test the connection

Make sure everything works:

```bash
opensre integrations verify --id trello-prod
```

This verifies that your API key and token are valid and that you're connected.
