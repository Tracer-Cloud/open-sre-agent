---
title: "Monitoring scheduled-agent work"
description: "Where to find the output and status of scheduled tasks, background jobs, and chat deliveries."
---

When you schedule investigations or run them in the background, OpenSRE delivers the results to the channels you configure. Here is where to monitor the progress and output of these jobs.

## Interactive Shell (`/background`)

If you launch an investigation in the interactive shell using `/background on`, the job runs asynchronously, leaving your shell free.

- **Check status:** Use `/background list` to see all tracked jobs.
- **View results:** Once a job is complete, run `/background show <task_id>` to view the root cause, analysis, and next steps.
- **Promote context:** Bring the results of a background job into your active shell context using `/background use <task_id>`.

Background completion notifications support the following channels:

| Channel | Set up with |
| --- | --- |
| `email` | `opensre integrations setup smtp` |
| `telegram` | `opensre integrations setup telegram` |
| `rocketchat` | `opensre integrations setup rocketchat` |
| `buzz` | `opensre integrations setup buzz` |

<Warning>
Slack and Discord are **not supported** as background notification channels. If you set them, the notification result will show `unsupported`.
</Warning>

For more details, see the [Background investigations](/background-investigations) documentation.

## Scheduled Tasks (Cron)

Recurring scheduled tasks created with `opensre cron add` execute automatically in the background while the scheduler daemon (`opensre cron start`) or gateway is running.

<Warning>
If no scheduler process is running, configured tasks will never fire and no execution history or delivery will appear. Start the daemon with `opensre cron start` or run `opensre gateway start` to ensure your tasks execute.
</Warning>

Cron delivery supports a different set of providers than background notifications:

| Provider | Notes |
| --- | --- |
| `telegram` | Requires `--chat-id` |
| `slack` | Uses incoming webhook or bot token; `--chat-id` optional with webhook |
| `discord` | Requires `--chat-id` |
| `rocketchat` | Requires `--chat-id` |
| `interactive_shell` | Delivers to the local shell inbox; no `--chat-id` needed |

- **List active cron tasks:** Run `opensre cron list` to view all configured tasks and their next fire times.
- **View execution history:** Use `opensre cron logs <task_id>` to see the execution history, statuses, and any errors for a specific task.
- **Interactive shell loops:** If you use `/loops add`, you can check their status using `/loops` and view recent messages with `/loops messages`.

For a deep dive into the scheduling system, refer to the [Scheduled Deliveries (Cron)](/cron) documentation.
