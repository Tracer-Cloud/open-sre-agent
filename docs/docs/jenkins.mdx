# Jenkins

The Jenkins integration allows OpenSRE to correlate CI/CD build and deployment activity with incidents.

## Features

- List Jenkins jobs
- List recent builds for a job
- Show build status and timestamps
- Fetch build console logs
- List currently running builds
- Inspect pipeline stages

## Configuration

Provide the following Jenkins settings:

- Jenkins URL
- Jenkins username
- Jenkins API token

## Use cases

- Correlate failed builds with alerts
- Investigate failed deployments
- Review pipeline stage failures
- Fetch Jenkins console output during RCA investigations
