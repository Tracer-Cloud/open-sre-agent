## Installation Methods

### 1. Install via pip/uv (Recommended for Python users)

**Requirements:** Python 3.12+, [uv](https://docs.astral.sh/uv/getting-started/installation/) (recommended for speed)

```bash
uv pip install opensre
# or, with pip
pip install opensre
```

**For development:**
```bash
git clone https://github.com/Tracer-Cloud/opensre.git
cd opensre
uv sync --frozen --extra dev
make install
```

### 2. Install via Homebrew (macOS/Linux)

```bash
brew tap tracer-cloud/tap
brew install tracer-cloud/tap/opensre
```

### 3. Install via Docker

```bash
docker pull tracercloud/opensre:latest
docker run --rm -it tracercloud/opensre:latest opensre --version
```

### 4. Install via Shell/PowerShell Script


**Unix/macOS:**
```bash
# You can inspect the script before running it:
curl -fsSL https://install.opensre.com | less
# Then install:
curl -fsSL https://install.opensre.com | bash
# For latest main branch:
curl -fsSL https://install.opensre.com | bash -s -- --main
```

**Windows (PowerShell):**
```powershell
irm https://install.opensre.com | iex
```

## Verifying Your Installation

Check your install and version:

```bash
opensre --version
opensre doctor
```

## Platform Notes

**macOS:** Homebrew and pip/uv are supported. For Apple Silicon, Homebrew installs to `/opt/homebrew/bin` by default.

**Linux:** Use pip/uv, Homebrew, or Docker. Ensure Python 3.12+ is available.

**Windows:** Use PowerShell script or pip. For best results, use [Windows Terminal](https://aka.ms/terminal) and ensure Python is in your PATH. WSL2 is fully supported.

**WSL2:** Install as on Linux. If you encounter permission issues, ensure your user owns the install directory.

---

## Common First-Run Errors & Fixes

**Error:** `opensre: command not found`
- Ensure your Python/Shell install directory is in your PATH. On Unix, add `~/.local/bin` or the Homebrew prefix to your PATH.

**Error:** `ModuleNotFoundError` or dependency errors
- Run `uv pip install opensre --force-reinstall` or `make install` in the repo root.

**Error:** Permission denied
- Try installing with `--user` or use a virtual environment.

**Windows:** If you see script execution errors, run `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` in PowerShell.
