Welcome to OpenSRE! This page guides you through all supported installation methods for local, on-prem, and enterprise environments.

## Installation Methods

### 1. Install via pip/uv

**Requirements:** Python 3.12+, [uv](https://docs.astral.sh/uv/getting-started/installation/) (recommended for speed)

```bash
uv pip install opensre

# or
pip install opensre
```

### Install from source (Development)

```bash
git clone https://github.com/Tracer-Cloud/opensre.git
cd opensre

uv sync --frozen --extra dev
make install
```

---

### 2. Install via Homebrew (macOS/Linux)

```bash
brew tap tracer-cloud/tap
brew install tracer-cloud/tap/opensre
```

---

### 3. Install via Docker

> **Note:** The official Docker image is `tracercloud/opensre:latest`. Verify the image name/tag in the Docker guide if you encounter issues.

```bash
docker pull tracercloud/opensre:latest

docker run --rm -it tracercloud/opensre:latest opensre --version
```

---

### 4. Install via Shell/PowerShell Script

#### Unix/macOS

```bash
# Inspect the script before running it
curl -fsSL https://install.opensre.com | less

# Install stable release
curl -fsSL https://install.opensre.com | bash

# Install latest main branch
curl -fsSL https://install.opensre.com | bash -s -- --main
```

#### Windows (PowerShell)

```powershell
# Inspect the script before running it
(Invoke-WebRequest https://install.opensre.com).Content

# Run installer
irm https://install.opensre.com | iex
```

> **Inspect before run:** Always review the PowerShell script content before executing it, just as you would on Unix systems.

## Verifying Your Installation

After installation, verify OpenSRE is working correctly:

```bash
opensre --version
opensre doctor
```

Expected output should show:

* installed OpenSRE version
* environment diagnostics
* dependency validation
* configuration checks

## Platform Notes

### macOS

* Homebrew and pip/uv installations are fully supported
* Apple Silicon installs Homebrew binaries under:

```bash
/opt/homebrew/bin
```

* Ensure Homebrew binaries are included in your `PATH`

### Linux

* Use pip/uv, Docker, or Homebrew
* Ensure Python 3.12+ is available:

```bash
python3 --version
```

* Some distributions may require installing:

  * `python3-venv`
  * `build-essential`

### Windows

* PowerShell installer and pip installs are supported
* Recommended terminal:

  * [Windows Terminal](https://aka.ms/terminal)

If Python commands fail, verify Python is available in PATH:

```powershell
python --version
```

If you encounter execution policy issues:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

### WSL2

* Install using Linux instructions
* WSL2 is fully supported

If permissions fail:

```bash
sudo chown -R $USER:$USER ~/.local
```

## Common First-Run Errors & Fixes

### Error: `opensre: command not found`

Your install directory may not be in PATH.

For Unix systems:

```bash
export PATH="$HOME/.local/bin:$PATH"
```

For Homebrew users:

```bash
export PATH="/opt/homebrew/bin:$PATH"
```

---

### Error: `ModuleNotFoundError`

Try reinstalling dependencies:

```bash
uv pip install opensre --force-reinstall
```

Or from source:

```bash
make install
```

---

### Error: Permission denied

Try:

* using a virtual environment
* installing with `--user`
* avoiding `sudo pip install`

Example:

```bash
pip install --user opensre
```

---

### Docker container exits immediately

Verify Docker is installed and running:

```bash
docker --version
docker ps
```

Then retry:

```bash
docker run --rm -it tracercloud/opensre:latest opensre doctor
```
